Sistema de Gestión de Repuestos

Aplicación de escritorio desarrollada en C# para la gestión de inventario y venta de repuestos.

Funcionalidades principales
Gestión de stock de repuestos
Alta, baja y modificación de productos
Control de inventario
Visualización de datos en interfaz gráfica

Tecnologías utilizadas
C#
.NET / Windows Forms
